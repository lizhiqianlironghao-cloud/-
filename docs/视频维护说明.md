# 添加与删除作品视频

当前公开作品集：https://grjl-3u2.pages.dev/#work

## 交给 Codex 更新

1. 把新视频放入 `E:\Codex\个人简历\作品集`。可以建子文件夹，原片保持不变。
2. 在这个聊天里说明文件名、网站上的作品名称，以及希望排在第几位。
3. Codex 会制作兼容浏览器的播放版本和封面，更新作品列表，检查播放，再发布到同一个网址。

删除时可以说：“从网站移除‘拾铁兽 · 新店探馆’，保留原片。”这会移除网站入口及对应发布素材，不删除 `作品集` 中的原始文件。

文件夹中的原片与已经上线的播放版本是分开的。往文件夹复制视频，或删除文件夹中的原片，都不会自动改变线上网站。

## 自己修改项目文件

1. 网页播放版本放在 `public/media/`，优先使用 H.264 视频与 AAC 音频的 MP4。封面放在 `public/images/`。
2. 打开 `src/content.js`，在 `projects` 数组中添加作品对象。每条作品的 `id` 必须唯一；以下是待填写的示例：

```js
{
  id: '04',
  title: '作品名称',
  subtitle: '点击观看完整视频。',
  category: '作品分类',
  image: '/images/work-04-cover.jpg',
  imageAlt: '这条作品的封面描述',
  tags: ['视频作品'],
  description: '作品简介',
  approach: [],
  video: '/media/work-04.mp4',
  durationLabel: '00:40', // 改成实际时长
  isDemo: false,
},
```

3. 删除作品时，从数组中移除整个对应对象。再移除不被其他作品使用的网页视频和封面文件。保留原片即可方便恢复。
4. 双击根目录的 `start-preview.cmd` 查看本地效果；修改后运行 `npm run build` 检查构建。
5. 本地修改不会自动发布。告诉 Codex“把当前改动同步到线上作品集”，才能让同一个公开网址更新。

首页“浏览作品”打开全屏作品展厅。展厅与“精选作品”模块共用 `projects` 数组，修改作品或调整数组顺序后，两处一起更新。点击视频卡片播放，点击“返回作品展厅”回到列表，关闭展厅回到首页。

## 线上发布记录

当前站点由 Cloudflare Pages 提供，源码仓库为 `https://github.com/lizhiqianlironghao-cloud/-`，使用 `main` 分支。完成构建检查后推送源码，再核对 `https://grjl-3u2.pages.dev/` 是否载入新的构建文件。

旧 Sites 站点身份保存在 `.openai/hosting.json`，旧发布 checkout 为 `sites/yiming-portfolio`，仅在需要更新旧 Sites 站点时使用。原始 `作品集`、本地依赖及临时目录不进入发布源码。

当前版本没有管理后台。如果需要在网页里自己上传、改名、排序和删除，并让所有访客立即看到更新，需要另行添加只供本人登录的管理后台及服务器端素材存储。
