# 动效编排

页面使用 GSAP 3.15 + ScrollTrigger，React 生命周期由 `@gsap/react` 的 `useGSAP` 管理。

- 首屏约 4.5 秒：艺名与横线先登场，左右幕布打开，背景由近景归位；中文标题逐字从遮罩下抬升，并由压缩状态恢复。
- 模块入口：英文大标题从下方大幅揭开，同时修正倾斜与纵向压缩；中文内容随后出现。
- 作品与优势：按实际网格行分组，每张卡片相隔 0.22 秒展开；位移、轻微旋转与缩放共同构成进场。
- 图片：遮罩向上揭开，图片由 1.2 倍回落到原尺寸；桌面端另有轻量滚动视差。
- 缓动以 `power4.out`、`power4.inOut`、`expo.out` 为主，无弹跳或弹簧。

动画只改变 transform 与 opacity。没有滚动锁定、滚动接管或持续循环动效。减少动态效果模式跳过开场与入场动画；键盘聚焦会立即展示相关内容。跳过开场按钮以及滚动、Escape 均可结束开场。

具体时间线：`src/motion/usePortfolioMotion.js`。

全屏作品展厅现采用分类作品网格：标题保持遮罩进场，卡片进入可视区域时由下方位移归位，图片遮罩上移、图像缩放归位；每批卡片错峰 0.09 秒。切换分类后重新编排，打开作品与返回时保留筛选和滚动位置。键盘聚焦立即展示对应卡片，减少动态效果模式直接展示。展厅不再运行横向自动循环，相关实现位于 `src/components/WorkShowcase.jsx`。

视觉样稿、千川工作场景、三列作品排列及联系方式延续当前页面内容。
